## 2. 🔴 DECIDE BEFORE WEDNESDAY

### 2a. 16" return or 18" (+$400) — the one that affects every running hour
Rev D did the arithmetic: at the design airflow a **16" return runs ≈713 ft/min, which the
drawing itself calls "the ACCA Manual D maximum for flex."** **18" runs ≈563 ft/min.**

Buying 16" is buying **zero margin** — and what eats margin all happens later: a loaded filter, a
sag, a kink, a crushed bend. **$400 is 4% of the job, paid once, on the part nobody opens again.**
**Recommendation: take the 18".** The extended *labour* warranties are not worth it; this is.

*(For reference, the competing Peters bid priced the same upsize at only +$160.)*

## 6. 🔬 ACCEPTANCE TEST — how we prove it was done right

**The contract already obliges them:** *"Will record startup supply and return static pressure and
airflow reading on invoice."* **Do not let the truck leave without those numbers.**

> The comparison doc puts it bluntly: on packaged units **almost every complaint traces to the
> install — charge, airflow, drain, gas pressure — which is why the static-pressure-on-the-invoice
> gate matters more than the badge.**

| Measurement | Judge it against |
|---|---|
| **Supply + return static, and TESP** | 🔴 Take the blower table's max external static off the **installation manual in the box**. The cabinet is specified at **0.5 in WC**, which is the design reference for this class — confirm against the book on the day |
| **Blower airflow** | **AHRI 950 CFM**, duct design **995 CFM**. Within ~10% |
| **Cooling temperature split (ΔT)** | **18–22 °F** return-minus-supply |
| **Heating temperature rise** | 🔴 **25–55 °F — the manufacturer's own stamped range.** Outside it, the gas side is wrong |
| **Refrigerant charge** | R-454B, **4.85 lb** nameplate |
| **A2L leak-detection system tested** | the unit **has one** — Rev D item 9 |
| **Dampers balanced** | 3 room upgrades + the garage |

🔴 **If TESP is over the rated maximum the job is NOT finished** — that is the measurement the
entire $1,800 duct line was bought to fix, and far cheaper to resolve while the crew is still here.

## 7. 🌡️ WHAT THE GARAGE VENT WILL ACTUALLY DO — set expectations now

From the 09-17 analysis, calibrated on **Jeff's own measurement** (94 °F with no AC; ~80 °F with
the LG portable):

| Setup | Garage settles at |
|---|---|
| Nothing (today) | **94 °F** |
| LG portable alone | ~80 °F |
| **7" vent alone, damper open** | **~84 °F** |
| **7" vent + the LG** | **~73–74 °F** |

The 7" branch carries **~125 CFM**, about **13% of the unit's capacity**. On a brutal afternoon,
**close the damper at the register** and the full airflow goes back to the house. Winter: same
damper, closed. The garage has no return, so it pressurises and leaks out around the door —
the right direction.

**Do not expect a cold garage from the vent alone.** It takes ~10 °F off. If Jeff later wants a
room he can work in all afternoon, **R-38 blown cellulose over the garage ceiling (~10 bags,
$120–150, an afternoon)** roughly doubles what the vent does — the ceiling is ~⅔ of the heat gain.
