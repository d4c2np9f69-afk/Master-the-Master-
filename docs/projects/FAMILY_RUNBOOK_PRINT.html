On Jeff's main PC (the one he calls "the beast"), open the program called Claude Code — or go to claude.ai/code in a web browser and sign in with Jeff's account. Then type, in plain English:

"I'm Jeff's wife / son. Jeff isn't available and I need help running the house. Read the project memory and tell me what I need to know."

  • "Something is beeping and I don't know what it is"

You cannot break anything by asking questions. Ask before touching.

If Claude says it can't open one of the key files

Claude is deliberately careful with files that hold passwords and keys, and now and then it will refuse to open one, saying something like "permission denied." Nothing you need is lost when that happens, and here is why:

  • Those files hold keys to the house gadgets — not to Jeff's accounts.
  • Every password Jeff owned is in Bitwarden, opened by the five words in the safe. That never depends on Claude being allowed to read anything. See the safe section above.
  • If a box pops up on screen asking whether to allow something, you are the one being asked, and you can click Allow.

That carefulness is on purpose, and it protects you: a stranger cannot talk Claude into opening Jeff's vault, because the only way in is the paper envelope in your safe.
