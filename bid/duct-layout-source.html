Required scope

  1. Unit connections: new square-to-round transitions on both supply and return at the package unit. Remove the existing twisted connections.
  2. Return: new 16" insulated flex straight back from the unit, a sheet-metal 90 across the supply trunk, and a second sheet-metal 90 into the return filter grille. 16" runs about 713 ft/min at 995 CFM, the ACCA Manual D maximum for flex; quote 18" (about 563 ft/min) as an option.
  3. Return filter grille: at least 3.3 sq ft of filter face (≤ 300 ft/min), e.g. 20 × 25. Replace the existing grille if smaller.
  4. Upgrade 6" → 8": Dining room, Master bedroom, Living room, each with a new saddle tap, balancing damper and boot.
  5. New 7" garage run: saddle tap on the side of the 12" supply trunk (not off the trunk end), balancing damper, boot and brown register; core through the brick and seal the penetration.
  6. Existing to remain: supply trunk 16" → 14" → 12" with reducers; Master bath 6" (one register, adequate), Guest bedroom 7", Office 6", Guest bath 6". Inspect, re-seal and re-strap. Replace any run with wet or damaged insulation.
  7. All flex: fully extended, no kinks, sags or compression; supported per manufacturer; every joint sealed with mastic or UL 181 tape. State the insulation R-value on the quote.
  8. Thermostat: new 18 AWG thermostat wire with C-wire from unit to thermostat (no power-stealing thermostats per the Carrier 48NL manual); install owner's thermostat.
  9. Start-up, recorded on the invoice: supply and return static pressure, dampers balanced, airflow set to 995 CFM, refrigerant leak-detection system tested where equipped.
  10. Permit pulled by the contractor; old equipment and debris removed.
