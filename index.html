📡 OBD-II Sensor Setup
Your 2001 F-250 has an OBD-II port under the dash. To get live engine data into this app:
  • Veepeak OBDCheck BLE+ (~$30) — plugs into OBD port
  • ESP32 + ESPHome — reads BLE adapter, pushes to Beehive
  • Optional: GPS module (NEO-6M, ~$12) for location tracking
Once connected, this tab will show live RPM, coolant temp, battery voltage, engine load, and diagnostic trouble codes.
